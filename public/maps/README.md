# Map artwork credits

The Earth mask and regional map were rendered for Bharat Lums using Natural
Earth 1:110m country outlines as distributed by World Atlas 2.0.2. Natural
Earth geographic data is public domain. The brochure artwork and partner
details were used for visual reference only.

- Natural Earth: https://www.naturalearthdata.com/about/terms-of-use/
- World Atlas: https://github.com/topojson/world-atlas
